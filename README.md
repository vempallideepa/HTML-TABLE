# HTML Marks Table

This project is a simple HTML webpage that displays student records in a table format. The table includes student details such as serial number, name, age, marks, and grade. It demonstrates the use of HTML table elements including rows, columns, headings, and data cells.

## Features
- Student information table
- Marks and grades display
- Clean and organized layout
- Beginner-friendly HTML code

## Technologies Used
- HTML5

## Purpose
This project was created to practice HTML table creation and data presentation in web development.
